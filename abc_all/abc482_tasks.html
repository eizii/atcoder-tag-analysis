You are given a simple undirected graph G with N vertices numbered 1 to N and M edges. The i-th edge connects vertices u_i and v_i.
You are also given a sequence of positive integers A = (A_1, A_2, \dots, A_N).
A spanning subgraph G' of G is called a good graph if it satisfies the following condition.

  • For every integer i with 1 \leq i \leq N, the degree of vertex i in G' is at most A_i.

Find the maximum possible number of edges in a good graph.

You are given T test cases; solve each of them.

Constraints

  • 1 \leq T \leq 10
  • 2 \leq N \leq 500
  • 1 \leq M \leq \frac{N(N-1)}{2}
  • 1 \leq A_i \leq N-1
  • \displaystyle \sum_{i=1}^N A_i \leq 500
  • 1 \leq u_i \lt v_i \leq N
  • (u_i, v_i) \neq (u_j, v_j) if i \neq j.
  • The sum of \displaystyle \left(\sum_{i=1}^N A_i\right)^3 over all test cases is at most 500^3.
  • The sum of M over all test cases is at most 2\times 10^5.
  • All input values are integers.

Input

The input is given from Standard Input in the following format:

T
\mathrm{case}_1
\mathrm{case}_2
\vdots
\mathrm{case}_T

Each test case \mathrm{case}_t is given in the following format:

N M
A_1 A_2 \dots A_N
u_1 v_1
u_2 v_2
\vdots
u_M v_M

Output

Print T lines. The i-th line should contain the maximum possible number of edges in a good graph for the i-th test case.

For the 1-st test case, the spanning subgraph whose edge set consists of only the 1-st, 3-rd, and 4-th edges is a good graph. No good graph with 4 or more edges can be constructed, so the answer is 3.
