        A - 解き方


この事実を使えば、次のように運ぶのが最適:

・ダンボールが 1 個しかないなら、それを運ぶ。 
・ダンボールが 2 個以上あれば、2 個運ぶ。

これをダンボールがなくなるまで繰り返して、 
そのときの回数が答えになる。

       A - プログラム


擬似コードで表現すると、こんな感じ:


                往復回数を初期化count ← 0            #
                ダンボールがまだある間while N > 0:         #
                残りが 1 個のとき  if N == 1          #
                その 1 個を運ぶ    N ← N - 1        #
                        2 個以上残っているとき  else               #
                        2 個まとめて運ぶ    N ← N - 2        #
                往復回数を 1 増やす  count ← count + 1  #

　残った 1 個を最後の 1 回で運べばいい。
