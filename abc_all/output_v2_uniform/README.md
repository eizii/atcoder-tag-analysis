# 難易度比較用：全問で同じ自動付与

対象3,012問、タグ語彙266種類。タグ付与済み2189問、未付与823問、観測タグ157種類、問題–タグ対応5089件。

旧898問のタグと27問の個別AIレビューを使わず、全問題に同じルールを適用した主比較用データ。未付与823問は「適用可能なタグがない」とは確定していません。

- problems.csv：全問題を1行ずつ保存（空タグを含む）
- all_problems_tagged.csv：問題–タグ対応ごとに1行
- problem_tag_matrix.csv：3,012問題×266タグの0/1行列
- source_scope_audit.csv：他問題と共有された未分割解説、説明用例題、参考文献等の除外
- rejected_evidence.csv：名前・説明・コードの根拠を採用しなかった理由
- problems_tagged.jsonl：出典本文と根拠（ローカル保存、ZIPには本文を含めない）

すべて暫定付与です。削除された根拠のすべてを誤付与と確認できたわけではありません。主解・別解・補助の全件判定は未実施です。

[比較結果と方法](../comparison_20261105/README.md)。外部AI APIは使用していません。追加API費用0円。
